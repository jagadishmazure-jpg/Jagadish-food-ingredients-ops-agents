# SOP-03: Trial Protocol

## Purpose
Standardises pilot trial batches so results are comparable across
reformulation cycles.

## Batch criteria
Every trial batch is scored on four criteria: sensory panel (0-10),
texture panel (0-10), shelf-life target met (yes/no), and micro panel
clear (yes/no). A batch passes only when sensory and texture are both
6 or above, shelf-life is met, and micro is clear.

## Failing batches
A failing batch records which criteria failed and a short note on the
suspected cause. The note must name the formulation change under test,
not restate the score.

## Cycle tracking
Trial cycles are counted per formulation. Formulations that fail three
batches on the same criterion return to draft for a formula rework
before further trials.
